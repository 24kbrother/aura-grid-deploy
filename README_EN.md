## 🤖 Feature Spotlight: AI Agent & MCP Gateway for Everyone

In **v1.6.0-LITE**, the core AI Agent architecture is fully accessible:
- **Multi-LLM Provider Support**: Native adapters for OpenAI-compatible, DeepSeek, Claude, Qwen, MiniMax, and Doubao.
- **Model Context Protocol (MCP)**: JSON-RPC gateway at `/api/v1/mcp` for direct integration with smart hardware like Xiaozhi AI and ESP32 terminals.
- **Fast-Path Intent Engine**: Local regex intent parser delivers sub-second execution without burning LLM tokens for standard commands.
- **Whole-Home Toolset (HomeTools)**: Comprehensive entity control covering lights, switches, climate, covers, and scenes.

## 🛡️ Aura Guard Security System

Built-in security protection for your terminal:
- **3-Strikes Rule**: Automatic 24-hour IP ban after 3 failed login attempts within 1 hour.
- **Hardware Identity (HWID)**: Unique node fingerprinting ensuring configuration isolation.
- **Node-RED Automation**: Instant security alerts forwarded to mobile devices via Home Assistant.
