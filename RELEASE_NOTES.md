# Aura Grid Release v1.4.16-STABLE

## 🚀 Key Improvements

### 🛠️ Critical Routing Fix (NestJS 11 / Express 5)
This release specifically addresses a critical routing crash encountered after upgrading to NestJS 11 and Express 5. The underlying issue was caused by the transition to `path-to-regexp` v6, which no longer supports anonymous wildcards (`*`).

**Key Changes:**
- **Named Wildcards**: Updated `ServeStaticModule` configuration to use named splat patterns.
    - `exclude` paths now use `*splat` or specific regex patterns compatible with Express 5.
    - `renderPath` has been updated from `/*` to `*splat` to ensure SPA routing works correctly without throwing `PathError`.
- **Production Stability**: This fix resolves the `TypeError: Missing parameter name` error that caused the backend to crash during boot or upon page refresh.
